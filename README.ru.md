# Плагин TorrPlay для Lampa

[English](README.md) | [Русский](README.ru.md)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.9-blue?logo=typescript)](https://www.typescriptlang.org/)
[![Lampa](https://img.shields.io/badge/Lampa-Plugin-purple)](https://github.com/yumata/lampa)

Официальный плагин [TorrPlay](https://github.com/torrplay/torrplay) для медиаплеера [Lampa](https://github.com/yumata/lampa). Воспроизводит торренты через TorrPlay на Android TV, Smart TV (Tizen, WebOS) и в браузерах.

---

## Возможности

- **Пул инстансов с выбором по задержке**:
  - Добавление и настройка нескольких инстансов TorrPlay.
  - **Автоматический режим**: плагин параллельно проверяет инстансы через `/api/system/health`, измеряет задержку и направляет запросы на самый быстрый из доступных.
  - **Переключение при сбое**: если активный инстанс перестает отвечать, плагин выбирает следующий доступный инстанс с наименьшей задержкой.
- **Предзагрузка перед просмотром**:
  - Запускает предзагрузку через `PUT /api/v1/torrents/{hash}/preload`.
  - Показывает прогресс, объем загруженного буфера и его целевой размер, скорость загрузки и число подключенных пиров.
  - Передает воспроизведение в `Lampa.Player.play()`, когда буфер достигает порога готовности.
- **База TorrPlay в боковом меню**:
  - Добавляет раздел **TorrPlay** с собственным компонентом `torrplay_torrents`. Раздел TorrServer `mytorrents` работает независимо; в режиме «Всегда TorrPlay» плагин скрывает его.
  - Показывает сохраненные в базе торренты с постерами, метаданными и выбором файлов.
  - Отмечает значком на постере торренты, которые хранятся на диске; показывает число файлов и размер.
- **Поиск через Jackett и Prowlarr**:
  - Отдельный пул поисковых провайдеров в **Настройки → TorrPlay → Управление провайдерами поиска**.
  - Параллельный поиск через все включенные провайдеры, удаление дубликатов и сортировка по числу сидов.
  - Переключатель **Показывать в общем поиске** в меню **Управление провайдерами поиска** добавляет вкладку **Jackett / Prowlarr** в общий поиск Lampa. На вкладке видны число найденных торрентов и полный список с датой, трекером, числом сидов, размером, качеством, аудиодорожками и субтитрами. Отдельная настройка **База TorrPlay в общем поиске** добавляет вкладку сохраненных торрентов с числом совпадений, карточками и списком файлов, как в библиотеке TorrPlay. При открытии общего поиска из библиотеки TorrPlay эта вкладка выбирается автоматически.
  - Когда включены TorrPlay и хотя бы один провайдер, плагин заменяет стандартный поиск торрентов Lampa. В остальных случаях используется стандартный поиск Lampa, если он доступен. Если стандартного поиска нет, плагин сообщает об ошибке.
- **Выбор способа воспроизведения**:
  - Кнопка **TorrPlay** в карточках фильмов и сериалов.
  - Действия **Смотреть через TorrPlay** и **Сохранить в TorrPlay** в контекстном меню торрента, которое открывается долгим нажатием.
  - Три режима: всегда использовать TorrPlay, спрашивать перед просмотром о выборе TorrPlay или TorrServer, либо запускать TorrPlay только через кнопку и контекстное меню.
- **Тип хранилища и сохранение в базе**:
  - **Оперативная память (`memory`)** или **Диск (`file`)**. Хранение на диске доступно только для торрентов, сохраненных в базе. При временном просмотре используется оперативная память, даже если выбран диск.
  - **Всегда** сохранять торренты в базе TorrPlay или **Никогда** — для временного просмотра.
  - Режим **Спрашивать перед просмотром** позволяет выбирать хранилище и сохранение в базе перед каждым запуском. Выбор можно запомнить.
- **Аутентификация и токены**:
  - Режимы `none`, `basic` и `bearer` для каждого инстанса.
  - **Bearer**: плагин получает JWT через `POST /oauth/token` и обновляет его перед истечением срока действия или при ответе HTTP 401.
  - **Токены воспроизведения**: для доступа к видеопотоку с аутентификацией плагин получает токен через `POST /api/v1/tokens` (`{"scope": "playback"}`).
- **Поддержка ТВ и браузеров**: плагин собирается в самостоятельный JavaScript-файл без внешних зависимостей для Android TV, Tizen, WebOS и браузеров на компьютере.

## Установка в Lampa

1. Откройте **Lampa** на устройстве.
2. Перейдите в **Настройки** → **Расширения**.
3. Нажмите **Добавить плагин**.
4. Введите URL собранного плагина:

   ```text
   https://your-domain.example.com/dist/torrplay.js
   ```

   Файл `dist/torrplay.min.js` также можно разместить на своем хостинге, CDN или GitHub Pages.
5. Перезапустите Lampa. Раздел **TorrPlay** появится в **Настройках** и боковом меню.

## Настройка

В Lampa откройте **Настройки** → **TorrPlay**:

| Настройка | Описание | По умолчанию |
|---|---|---|
| **Включить TorrPlay** | Просмотр и поиск торрентов через TorrPlay. При воспроизведении через TorrPlay Lampa пропускает рекламу перед видео | `Включено` |
| **База TorrPlay в общем поиске** | Поиск сохраненных торрентов на активном инстансе через общий поиск Lampa | `Отключено` |
| **Выбор инстанса** | `Авто (наименьшая задержка)` или `Выбор вручную` | `Авто (наименьшая задержка)` |
| **Управление пулом инстансов** | Добавление и редактирование инстансов, учетные данные, проверка задержки и выбор активного инстанса | Меню действий |
| **Управление провайдерами поиска** | Добавление и редактирование провайдеров Jackett и Prowlarr, проверка задержки. Когда TorrPlay и хотя бы один провайдер включены, здесь также доступен переключатель **Показывать в общем поиске**. Он добавляет отдельную вкладку результатов и при первом включении использует настройку общего поиска торрентов из Lampa | Меню действий |
| **Воспроизведение торрентов** | `Всегда TorrPlay`, `Вручную (кнопка и меню)` или `Спрашивать перед просмотром (TorrPlay / TorrServer)` | `Всегда TorrPlay` |
| **Тип хранилища** | `Оперативная память`, `Диск` или `Спрашивать перед просмотром`. Для хранения на диске нужно сохранение в базе; при временном просмотре используется оперативная память | `Оперативная память` |
| **Сохранение в базе** | `Никогда`, `Всегда` или `Спрашивать перед просмотром` | `Никогда` |
| **О плагине** | Версия плагина и информация о сборке | Информация |

## Безопасность и хранение учетных данных

- **Обфускация сохраненных паролей**: перед записью в `Lampa.Storage` (`localStorage` или хранилище WebView) плагин обрабатывает пароли обратимым шифром с префиксом `enc:v1:`. Это скрывает пароли от случайного просмотра хранилища, в том числе при демонстрации экрана или выгрузке его содержимого.

  > [!NOTE]
  > У JavaScript-плагина в браузере или WebView телевизора нет доступа к защищенному аппаратному хранилищу или системному хранилищу ключей. Обфускация затрудняет случайный просмотр пароля, но не защищает от человека с полным доступом к устройству или исходному коду плагина.

- **Токены только в памяти**: краткоживущие JWT и токены воспроизведения хранятся в оперативной памяти. Плагин не записывает их на диск или в постоянное хранилище.
- **Общие устройства**: если к хранилищу телевизора или профиля имеют доступ другие плагины и скрипты, используйте для TorrPlay отдельные учетные данные с ограниченными правами на просмотр.

## Интеграция с Lampa

Плагин передает каждому элементу воспроизведения и плейлиста `Lampa.Player` признак `continue_play: true`, а сам плейлист — до начала просмотра. Lampa пропускает рекламу VAST перед видео, пока такой элемент находится в текущем плейлисте. При переключении серии Lampa очищает плейлист, поэтому TorrPlay восстанавливает его до проверки рекламы для следующей серии. Признак `torrent: true` также передается, но лишь обозначает торрент-воспроизведение.

## Разработка и сборка

### Требования

- [Node.js](https://nodejs.org/) 24.x начиная с 24.18.0 либо 26.4.0 и новее.
- `npm`.
- Google Chrome или Chromium для проверки верстки страницы установки. По умолчанию тесты запускают `google-chrome`; путь к другому исполняемому файлу Chrome или Chromium можно задать через `CHROME_BIN`. Если браузер не найден, тесты верстки пропускаются.

### Установка зависимостей

```bash
npm install
```

### Проверка качества

CSS-свойства следуют порядку RECESS из `stylelint-config-recess-order`. Тесты проверяют таблицы стилей, блоки `<style>` и атрибуты `style`; порядок пользовательских CSS-свойств остается на усмотрение автора.

Тест верстки страницы установки запускает Chrome без графического интерфейса и проверяет выравнивание панели навигации, видимость версии и работу меню на обоих языках, в обоих каналах выпуска, при мобильной и настольной ширине экрана.

Перед коммитом выполните проверки:

```bash
# Запустить тесты
npm test

# Проверить типы TypeScript
npm run typecheck

# Проверить код с ESLint
npm run lint

# Автоматически исправить ошибки оформления
npm run lint:fix

# Собрать файлы для распространения
npm run build
```

Результат сборки:

- `dist/torrplay.js`: самостоятельная сборка без минификации, с картой исходного кода.
- `dist/torrplay.min.js`: минифицированная сборка.
- `dist/index.html`: страница установки со ссылками на плагин и документацию.
