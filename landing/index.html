Torrent Streaming for Lampa

A Lampa plugin for playing torrents, with buffering and a multi-instance pool.

Prerequisite

TorrPlay Application Required

This plugin is a client for Lampa. Torrent streaming requires a running, self-hosted TorrPlay application. Set up TorrPlay first, then connect the plugin to it.

Features

Features

Multi-Instance Pool

Pings all TorrPlay instances in parallel, routes to the lowest latency, and fails over if one drops.

Preload Buffering

Buffers torrent stream pieces to a readiness threshold before handing off to the player, with poster art and speed stats.

Database Torrents

Browse database torrents with poster badges, select multi-file episodes, and sync with the Lampa sidebar.

RAM & Disk Storage

Stream in RAM to avoid writing to disk, or use disk storage for large library torrents.

Bearer & Basic Auth

OAuth2 JWT for API control, with short-lived scoped tokens for video stream URLs.

TV Remote Support

Native Lampa dialogs, masked password entry, and D-pad navigation on Android TV, Tizen, and WebOS.

Jackett & Prowlarr Search

Searches all enabled providers concurrently, tolerates individual failures, removes duplicates, and sorts by seeder count.

Setup

How to Install in Lampa

  1. 1
    Open Lampa on your TV or device, navigate to Settings (Настройки) → Extensions (Расширения).
  2. 2
    Click Add Plugin (Добавить плагин).
  3. 3
    Paste the copied Production URL (torrplay.min.js) and confirm.
  4. 4
    Restart Lampa. A dedicated TorrPlay entry will appear in Settings (Настройки) and the main sidebar.
